# riverbend-demo

**This is synthetic demonstration data, not a benchmark.** Every item was
written by hand for this repository to demonstrate the Plumbline instrument:
its integrity protection, its suites, and its warning paths. It measures
nothing about any real chat system, jurisdiction, program, or policy.

- "Riverbend County" and its "Rent Relief" program are inventions. All
  amounts, dates, limits, and office hours are made up. Domains use
  `.example`. The "recorded responses" were written alongside the items; there
  is no real target system behind them.
- English/Spanish item pairs share a `fact_id` so the cross-language agreement
  suite (milestone 2) has something to exercise.
- Items `rb-001`–`rb-004` and `rb-006` are marked `load_bearing`: numeric
  policy facts whose failure fails the accuracy suite regardless of the pooled
  average.
- Item `rb-004` deliberately carries `"review": "unreviewed"` so the
  unreviewed-translation warning appears on every demo run, as the spec
  requires (visible, never fatal, never suppressed).

Layout: see DESIGN.md ("Evidence bundle format"). Integrity: `checksums.json`,
generated by `plumbline seal`; any edit to this bundle without re-sealing makes
every subsequent run refuse to score (exit 3).
